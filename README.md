# CMPE 255 – Data Mining
## Colab Execution & Video Explanation Assignment

This repository contains my completed Google Colab notebooks and the corresponding video explanations for the CMPE 255 Data Mining refresher assignment.

For each notebook, I:
- copied the provided Colab into my Google Drive,
- executed the notebook and saved the outputs,
- reviewed the theory behind the important code blocks,
- recorded a video explaining the notebook code block by code block,
- archived the executed notebook in this GitHub repository.

The focus of the videos is on the important AI/ML concepts, code logic, theory, and outputs rather than UI/UX-related code.

## What I Focused on in the Videos

The video explanations focus on:
- the purpose of each important code block,
- the theory behind the code,
- the meaning of the outputs,
- how the concepts connect to AI, machine learning, and deep learning,
- core topics such as tensors, vectorization, linear algebra, probability, statistics, calculus, optimization, and neural-network architecture.

Visualization-only or UI/UX-related implementation details are kept brief unless they are important for understanding the concept.
