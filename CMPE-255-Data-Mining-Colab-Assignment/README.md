# CMPE 255 – Data Mining
## Colab Execution & Video Explanation Assignment

This repository contains my completed Google Colab notebooks and the corresponding video explanations for the CMPE 255 Data Mining refresher assignment.

For each notebook, I copied the provided Colab into my Google Drive, executed it with outputs saved, reviewed the theory behind the important code blocks, recorded a video explanation, and archived the executed notebook here.

The videos focus on the important AI/ML concepts, code logic, theory, and outputs rather than UI/UX-related code.
